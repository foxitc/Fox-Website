# Website and campaign landing pages

**Status:** composition guidance PROPOSED; existing website copy/routes/services LOCKED.

## Homepage
Navigation with original wordmark, existing service categories and support links. Strong existing headline (do not replace without approval), concise subhead, clear CTA, large photographic exact-arc hero on one side. Trust strip with verified customer evidence, services grid linking to existing service URLs, sector pathways, people-first proof, testimonials/case studies if verified, CTA and full footer. Use 12-column desktop layout, stacked mobile, max content width ~1200px (proposed).

## Industry landing page
Reusable component with industry config: slug, hero image, original approved heading or draft heading, challenge cards, relevant existing service links, genuine sector evidence, FAQs, CTA, UTM attribution and canonical metadata. First: `/industries/hospitality`, `/industries/freight-logistics`. Additional draft options: professional services, construction. No duplicate service page content or fabricated sector experience.

## Arc use
Hero: one oversized photo-mask symbol; secondary content: alternate orientation watermark; footer: restrained pulse if reduced motion permits. Use image focal points per arc. Never recreate with circular CSS strokes.

## Web UX and technical
Mobile 360px+, tablet, desktop; semantic heading hierarchy; keyboard support; WCAG AA contrast; target good Core Web Vitals; no broken hotlinks. Preserve existing routes, copy, CMS, forms, CRM, SEO, analytics and service catalogue. Create staging previews and screenshot QA. Industry campaign variants should not produce duplicate indexable pages; UTM params are tracking only, with canonical URL.

# Quality gate — score before delivery

Score each criterion 0 (fail), 1 (needs work), 2 (pass); minimum 18/20 AND no hard fail to label READY_FOR_REVIEW. This does NOT imply approved for publication.

1. Correct Fox ITC original logo and exact arc source geometry.
2. Appropriate arc orientation/treatment without stretching or overuse.
3. Correct colour tokens and restrained orange use.
4. Clear typography, hierarchy and generous whitespace.
5. Realistic, licensed and contextually relevant imagery; no fabricated employees/customers.
6. Correct existing services, pricing and claims with traceable sources.
7. Strong audience relevance, one main CTA and logical information order.
8. Accessible contrast, mobile-safe layout, alt text and reduced-motion support where relevant.
9. Correct format size, crop/safe area, export/editability and channel compatibility.
10. Professional finish: alignment, consistent SVG icons, no clipped content or broken links.

Hard fails: wrong arc geometry, altered logo, invented proof/claims, broken preview assets, unreadable text, unlicensed images, missing privacy/legal review for AI synthetic media where relevant. On hard fail, regenerate or flag for human review.

Output manifest: asset title, intended audience, channel, version, sources, image licences, QA score, unresolved approvals, editable source path, final export path, status.
